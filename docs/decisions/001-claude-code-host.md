# 001. Подключение роутера к Claude Code с исполнителями Claude и Codex

Дата: 8 ноября 2026 года. Статус: принято Хабибом.

## Задача

В обычной сессии Claude Code основная модель делит задачу на части, а роутер
выбирает для каждой части модель и effort. Исполнители — субагенты Claude и
запуски Codex. OpenRouter оплачивает только выбор.

## Решение

Код сервера и установленный плагин Codex не меняются. Подключение сделано на
уровне пользователя, а не отдельным плагином Claude.

| Что | Где |
|---|---|
| MCP-сервер `decision-router` | `~/.claude.json`, запускает `server/main.py` из этой папки |
| Навык и правила выбора | `~/.claude/skills/route-subagents/SKILL.md` |
| Профили исполнителей | `~/.claude/skills/route-subagents/profiles.json` |
| Разрешения инструментов роутера | `~/.claude/settings.json` |
| Автоматический запуск | раздел в `~/.claude/CLAUDE.md` |
| Запуск Codex | `scripts/run_codex_task.py` |
| Установка на другой машине | `scripts/install_claude_code.py`, шаблоны в `claude-code/` |

## Почему так

- Сервер универсален: поле модели — строка, логика выбора от хоста не зависит.
- Отдельный плагин потребовал бы копирования сервера в кэш Claude и второго
  источника правды. Прямой запуск из этой папки проще.
- Сервер не запускает исполнителей, поэтому для Codex нужна обёртка. Она всегда
  передаёт модель и effort явно: в `~/.codex/config.toml` по умолчанию стоит `max`.
- Обёртка запрещает `danger-full-access` и `ultra`, не считает старый отчёт
  результатом нового запуска.
- Профили и таблица допустимых вариантов основаны на сравнении от 8 ноября:
  публичные тарифы OpenAI и оценки Artificial Analysis при максимальном effort.

## Проверки 8 ноября

- 38 модульных тестов проходят, HTTP и Codex в них подставные.
- `claude mcp get decision-router`: сервер подключён.
- Живой вызов OpenRouter на 8 синтетических задачах: Drex Max уверенно решил 7,
  по одной задаче вызван Jev 1.14, он тоже не уверен, применён заранее заданный
  профиль. Стоимость $0.00023, время 2.4 с.
- Обёртка выполнила задачу через `gpt-6.1-terra`, модель и effort подтверждены
  журналом Codex.
- Субагент с `model: haiku` ответил моделью `claude-haiku-5-5` по данным ответа
  API: подмены модели нет. Его пустой запуск создал около 49 тысяч токенов кэша.
- Автоматический запуск в новой сессии не проверялся.

## Границы

- Автоматика держится на инструкции в `CLAUDE.md`, а не на хуке.
- Экономия и качество выбора на реальных задачах не измерены.
- При переустановке плагина Codex новые файлы этой папки попадут и в его кэш;
  на работу плагина они не влияют.
- Поля `mode: native_codex_plan` и описание `route_tasks` по-прежнему упоминают
  только Codex. На поведение это не влияет.
