# Пять моделей для распределения субагентов Codex

Проверено 3 ноября 2026 года. Цель: оплачивать в OpenRouter только решения,
а работу субагентов выполнять через штатный доступ Codex. Ниже опубликованные
данные; собственных живых вызовов этих моделей в рамках проверки не было.

## Цена и наблюдаемая задержка OpenRouter

| Модель | USD / 1 млн входных токенов | Выход | P50, мс | Контекст карточки |
|---|---:|---:|---:|---:|
| [Jev 1.13](https://openrouter.ai/typesafe/jev-1.13) | 0.042 | 0 | 90 | 262K |
| [Jev 1.14](https://openrouter.ai/typesafe/jev-1.14) | 0.042 | 0 | 130 | 262K |
| [Drex v1.5](https://openrouter.ai/nace-ai/drex-v1.5) | 0.040 | 0 | 190 | 131K |
| [Drex v2.0](https://openrouter.ai/nace-ai/drex-v2.0) | 0.060 | 0 | 340 | 131K |
| [Drex Max](https://openrouter.ai/nace-ai/drex-max) | 0.060 по скидке, базовая 0.120 | 0 | 320 | 262K |

P50 — медиана на карточках, best provider, выбранный период 1 week. Это
не испытание одинаковых запросов из России и не гарантия задержки плагина.
У Max указана скидка 50%; срок её окончания не установлен. Типы токенизаторов
и объём реально учтённого входа могут различаться.

Иллюстрация: 10 000 вызовов × ровно 2 000 учтённых входных токенов = 20 млн.
Jev стоит $0.84, Drex v1.5 — $0.80, v2.0/Max по текущему тарифу — $1.20,
Max без скидки — $2.40. Не включены комиссии пополнения, налоги, повторы и
расходы Codex. v1.5 дешевле Jev на 4.76%; v2.0/Max дороже на 42.86%.

## Два независимых индекса: разные методики

| Модель | Decision Index 0.4.1 Full | Artificial Analysis Decision Index |
|---|---:|---:|
| Jev 1.13 | 59.2 | 58 |
| Jev 1.14 | 60.2 | 57 |
| Drex v1.5 | 45.8 | 51 |
| Drex v2.0 | 52.8 | 58 |
| Drex Max v1 | 66.6 | 64 (метка Drex Max без номера ревизии) |

Источники:
[Decision Index 0.4.1](https://multimodalart-jev-decision-index.static.hf.space/index.html)
(обновление, указанное на странице: 29 октября),
[Artificial Analysis](https://artificialanalysis.ai/evaluations/artificial-analysis-decision-index)
(включены все 20 моделей, включая старые версии Jev и Drex).
Значения AA округлены интерфейсом до целых. Это баллы составных индексов,
а не процент успешных задач разработки.

Full состоит из 60% закрытых тестов тех же навыков и 40% закрытых задач новых
доменов. Публичная часть не входит в Full. AA независимо измеряет четыре
других набора: AA-Omniscience-Decision, HLE-MultiChoice, When2Call и
WildGuardTest. Сравнивать числа между колонками нельзя.
[Методика Full](https://github.com/apolinario/decision-index),
[методика AA](https://artificialanalysis.ai/evaluations/artificial-analysis-decision-index).

## Что утверждает производитель

В официальном репозитории Nace опубликованы результаты открытой части:
Drex v1.5 — 58.08, v2.0 — 61.25, Max v1 — 67.52, Jev 1.13 — 57.96.
Это авторские запуски Drex и строка Jev из публичной таблицы, не Full.
[Drex v1.5](https://github.com/nace-ai/drex-decision-models/blob/main/models/drex-v1.5/README.md),
[v2.0](https://github.com/nace-ai/drex-decision-models/blob/main/models/drex-v2.0/README.md),
[Max v1](https://github.com/nace-ai/drex-decision-models/blob/main/models/drex-max-v1/README.md).

На сайте Nace уже рекламируется **Max v1.1**: public 70.8 против 60.7 у
Jev 1.14; JevBench 93.9 против 86.7; When2Call 91.8 против 81.7.
При этом в их же таблице Jev впереди на MMLU-Pro (82.1 против 75.2) и HLE
(19.4 против 18.2). Это данные Nace о конкретной ревизии, а не доказательство
универсального превосходства. Связь OpenRouter slug `nace-ai/drex-max` с
Max v1.1 не удалось подтвердить. Производитель также приводит иные цены
за 1000 решений; они не заменяют тариф OpenRouter за входные токены.
[Официальная страница Nace](https://www.nace.ai/drex).

У OpenRouter есть собственный прогон Jev 1.13 на Banking77: 3 080 запросов,
accuracy 81.0%, P50 175 мс, P95 270 мс, $0.34 за весь прогон. Эти числа
нельзя напрямую сопоставлять с другими Banking77-прогонами, где отличаются
критерии и метрика. Сам OpenRouter отмечает, что confidence не равен
эмпирической вероятности правильного ответа.
[Прогон OpenRouter](https://openrouter.ai/blog/insights/jev-vs-claude-opus-5-classification/).

## Решение для этого инструмента

Предварительный кандидат по качеству — Drex Max; по небольшой задержке и
цене — Jev 1.14, с Jev 1.13 как дополнительным кандидатом. Jev 1.14 не
побеждает 1.13 во всех тестах. v1.5 экономит слишком мало, чтобы заранее
принимать заметное снижение качества; v2.0 при текущей скидке Max имеет
ту же цену и выглядит менее убедительно. Это вывод по опубликованным
данным, а не результат испытания маршрутизации Codex.

Ошибочная отправка сложной задачи слабому агенту может израсходовать больше
лимита Codex на переделку, чем сэкономит разница тарифов маршрутизатора.
Пользователь выбрал Drex Max основной моделью, Jev 1.14 резервной.
В версии 0.2.0 это стандартная цепочка: максимум один вызов каждой модели,
резерв повторно оценивает только спорные решения. Явные параметры позволяют
выбрать другую модель или отключить резерв для контрольного сравнения.

Для выбора по реальным результатам нужны 50–100 характерных русскоязычных
задач: чтение, архитектура, код, проверка; ожидаемый достаточный профиль;
прогон одинакового состояния через пять моделей; измерение фактических
входных токенов, USD, P50/P95, неудачных решений, повторов и качества работы
назначенного исполнителя. Разделять набор настройки порогов и итоговый
контрольный набор. Порог уверенности подбирать отдельно для каждой модели.

Модели принятия решений не знают свежую сравнительную силу доступных
субагентов автоматически. Их профили и критерии должны поступать из хоста
и обновляться по фактическим результатам. Большой промпт сначала разбирает
основная модель; этот начальный расход подписки маршрутизатор не убирает.
